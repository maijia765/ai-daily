Google 搜索 AI Mode 接入 Wallet，Drive 与 Gemini 应用随后跟进

Google 11 月 23 日宣布，搜索 AI Mode 的 Personal Intelligence（个性化智能）即日起开始接入 Google Wallet：用户自愿连接后，AI Mode 可以读取钱包里的消费记录与关联银行卡信息，回答"这个月花了多少""哪张卡返现更高"这类问题，并帮用户规划消费与理财目标。Google 强调连接完全自愿、可随时断开，且 AI Mode 只能读取账户信息，不能动用、管理或投资用户的钱。Drive 与 Gemini 应用的接入将在随后几周内上线：前者让 AI Mode 参考文档、表格与 PDF 回答问题，后者实现 Gemini 应用与搜索之间的上下文互通。此前 Personal Intelligence 已支持 Gmail、日历与照片。

为什么重要： Google 正在把搜索从"查公开信息"变成"查你自己的生活"：邮箱、日历、照片之后，消费记录和私人文档也要成为答案的输入。功能本身实用，但边界全靠"自愿连接"这道开关守着——一旦用户习惯了把钱包交给搜索，搜索就从一个工具变成了一个掌握你财务全貌的入口。

开发生态

Anthropic 发布 Claude Ship：AI 智能体接管代码评审、修复与合并审批

Anthropic 11 月 23 日发布 Claude Ship（一套 AI 智能体工具），把代码从"写完"到"上线"之间的评审、修复与审批环节也交给 Claude。套件由三部分组成：已正式上线的 Code Review（审 PR、找 bug 与安全问题，分 Quick、Standard、Deep 三档）；新进入 beta 的 PR Steward（处理失败的 CI 检查、合并冲突与评审意见，每次推送后说明改了什么、如何撤销）；以及同样 beta 的 Claude Approvals（按团队写在仓库里的审批策略文件，自动批准符合条件的常规改动，Anthropic 建议先以仅观察模式运行）。开发者在 Claude Code 里跑一条 /ship 命令即可走完全流程。Claude Ship 面向 GitHub 上的 Claude Team 与 Enterprise 计划客户，按 token 计费；零数据留存、HIPAA 配置与客户自管加密密钥的组织暂不能用，符合条件的 Enterprise 客户可在 2027 年 1 月 15 日前领取至少 1 万美元的使用额度。

为什么重要： AI 写代码的速度早已超过人类审代码的速度，评审与合并成了新的瓶颈——Claude Ship 就是 Anthropic 对这个瓶颈的回答。真正值得盯的不是"能自动批 PR"，而是"按团队策略自动批"：审批权一旦交给模型，策略文件写得松不松、出了问题谁负责，就成了每个团队必须先想清楚的事。

智谱发布 GLM-5.4：28 层循环跑两遍，7500 亿参数自称可比 2–3 万亿模型

智谱（Z.ai）11 月 23 日发布旗舰模型 GLM-5.4，首个采用 Loop Transformer 架构的旗舰：把 GLM-5 基础模型的 28 层权重共享层在每次前向传播中跑两遍，用计算深度换智能，不增加参数量，总参数约 7500 亿，官方称智能水平可比 2–3 万亿参数的模型。相比上一代 GLM-5.3，新模型增加了视觉能力（可读截图与图片），上下文 100 万 token，官方称非高峰期推理速度可达每秒 200 token、高峰期 70–80 token。模型即日起向 GLM Coding Plan 订阅用户开放，可在 ZCode 与 Z.ai Chat 中使用，Claude Code 里的模型名为 glm-5.4[1m]；API 需待安全评估后开放，权重计划在完成安全加固后开源。需要注意：官方尚未公布旗舰模型的跑分表，"可比 2–3 万亿参数"的说法目前只有 30B 规模的对照消融实验支撑（AIME25 从 19.17 升至 30.42）；官方自己也承认模型有时会陷入过长的"马拉松式思考"循环。

为什么重要： 这是国产旗舰第一次把"循环深度"当作与"堆参数"并列的扩展路线，并且拿出了可落地的工程方案（门控渐进更新、混合 KV 缓存、稀疏注意力索引复用）。但发布时没有旗舰跑分、没有 API、没有权重，"可比 2–3 万亿"目前还只是厂商自己的说法——等独立评测与 API 上线，才能验证循环这条路到底能走多远。

行业动态

两州起诉 SpaceX：Grok 被指批量生成未成年人色情图片，首例州级诉讼

弗吉尼亚与俄勒冈两州总检察长 11 月 23 日分别在州法院起诉 SpaceX 及其 AI 子公司 SpaceX Super Intelligence，指控 Grok 的图片生成功能把真人照片变成性化图片与视频，其中包括疑似未成年人的内容，违反州消费者保护法。这是首批针对 Grok 性化图片功能的州级诉讼。此前多个州总检察长已宣布调查，但尚未起诉。诉状称，SpaceX 在推广 Grok"spicy mode"时误导消费者、夸大安全防护效果，而该模式允许用户拿一张真人照片生成裸露或性化图片；弗吉尼亚州的诉状引用反数字仇恨中心（CCDH）的研究数据：2025 年 12 月 29 日至 2026 年 1 月 8 日间，Grok 在 X 上生成并发布了约 300 万张性化图片，其中约 2.3 万张疑似描绘未成年人。两州要求赔偿、民事罚款与法院禁令。SpaceX Super Intelligence 回应称，涉及未成年人的性内容"无论真实还是 AI 生成，都是令人厌恶的，在 X 或 Grok 中都没有立足之地"。除这两起诉讼外，SpaceX 还面临十余起来自个人的诉讼，以及巴尔的摩市、英国媒体监管机构与加州总检察长的调查。

为什么重要： 这是 AI 安全争议第一次从"平台删帖不力"的舆论层面，升级为州政府以消费者保护法直接起诉模型开发商——指控的核心不是"有人滥用工具"，而是"产品设计本身就没有装上显而易见的安全防护"。如果法院采纳这一逻辑，AI 公司的安全责任边界将被重新划定：上线前没做防护，本身就是违法。
