OpenAI Decisions API 正式 GA：GPT-6 Luna 驱动，10 倍速，只收输入 token 的钱

10 月 22 日，OpenAI 宣布 Decisions API 正式 GA。这是一个专用决策接口：把 GPT-6 Luna 的智能聚焦在"答案有界"的问题上（分类、路由、打分），从文本、图像和结构化输入中做近实时决策，速度比走 Responses API 调 GPT-6 Luna 快 10 倍。开发者定义问题和允许的答案，API 返回三种答案类型之一：概率（predicate）、选项（choice）、评分（score）。公测后新增：原生 GPT-Live 集成（语音 agent 通话中实时做决策，如判断是否追问、转接或升级）、prompt caching、美欧两地推理驻留、原生 JSON 输入、单次请求最多 400 个问题（翻倍）。定价：每百万输入 token 0.10 美元，缓存输入 0.01 美元，不收输出 token 费用。OpenAI 内部已在用：dots 团队用它降延迟，财务团队用它分类交易描述，传播团队用它给媒体报道打分。

为什么重要： 这是 OpenAI 把"小模型做小事"产品化的关键一步——agent 工作流里 90% 的调用都是分类、路由、打分这类"小决策"，用旗舰模型做等于高射炮打蚊子。Decisions API 的定价（只收输入钱）直接瞄准了这类高频调用的成本结构，也意味着 OpenAI 开始按"任务粒度"而不是"模型大小"来切分 API 市场。

Google Cloud 发布 Agent Compute Engine：每个 AI agent 一台硬件隔离 microVM

10 月 22 日，Google 在 AGNTCon + MCPCon 上发布 Agent Compute Engine——专为规模化运行 AI agent 设计的计算服务。每个 agent 运行在独立的硬件隔离 microVM 里（独立 guest kernel、root 权限、Titanium 芯片加固）；通过写时复制内存共享和快速检查点暂停/恢复来降本：agent 进入"思考"阶段时 microVM 自动暂停，20 万个 agent 的暂停/恢复延迟小于 500 毫秒，Google 号称密度可达传统方案的 10 倍。该服务已在支撑 Gemini 自身的 work agent、Gemini 平台、Antigravity 以及内部评测/强化学习管线，未来数月开放预览。同步开源了 Kubernetes 运行时 Agent Substrate（零信任架构），并扩展 agent 治理能力：token 与成本管控、模型路由、Agent Registry、基于 SPIFFE 的 Agent Identity、OpenTelemetry 可观测性，以及 Ping Identity、SailPoint 等第三方身份集成，覆盖 Cloud Run、GKE 等运行时。

为什么重要： Google 把 agent 沙箱从软件容器升级到了硬件隔离的 microVM——这与 NVIDIA 同一周推的 OpenShell agent 沙箱标准遥相呼应：agent 基础设施的安全与成本，正在成为云厂商的新战场。当每个 agent 都要一台"电脑"时，谁能把单 agent 成本压到最低，谁就掌握了 agent 时代的定价权。

NVIDIA 发布 Minerva AIOps 平台：给"AI 工厂"做端到端可观测性

意大利落实 EU AI Act 的 179/2026 号法令今日生效：雇佣决策最终必须由人类作出

意大利 2026 年第 179 号立法法令（落实欧盟 AI 法案的国内法）于 10 月 23 日生效。该法令 10 月 8 日刊于《官方公报》，共 54 条。据意大利劳动法界梳理，关键的第 41 条规定：雇佣关系的建立、变更、终止（含纪律处分和绩效评估）不得完全依赖自动化处理，最终决定必须由拥有实际自主决定权的自然人作出；违规作出的解雇无效；员工可要求对 AI 系统的权重和主要参数作出可理解的解释。候选人筛选阶段不算"最终决定"，仍适用 GDPR 相关规则。法令同时要求雇主把影响工作组织、排班的 AI 系统纳入强制性的工作场所风险评估文件（DVR）。

为什么重要： 这是 EU AI Act 在第一个大成员国的落地法令生效，"人类最终决定"从此是法定硬性要求，不再是伦理倡议。对部署 HR agent 和自动化管理工具的企业来说，合规红线已经划下：AI 可以给建议、打分、排序，但签字的必须是人。欧盟各国的跟进版本会陆续到来，跨国企业的 agent 部署方案得重做一遍合规检查。
